# AI Photo Studio

Free, no-signup AI image tools that run right in the browser.

## Tools

- **Background Remover** — remove the background from any image in seconds and download a clean transparent PNG (JPG, PNG & WebP supported).
- **Image Upscaler** — upscale photos to 4x resolution with crisp, realistic detail — no quality loss.

No watermarks. Unlimited use. No account required. Privacy-first: uploaded images are processed and never stored.
